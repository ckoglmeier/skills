# Venture Discovery

Two skills that turn a fuzzy startup or product idea into a decision.

- **`venture-concept-discovery`** — the end-to-end method. Frames the concept as one testable thesis, runs a sectioned discovery pass, and returns a GO / RESHAPE-THE-WEDGE / NO-GO verdict with a 7-dimension rubric, a committed wedge, pre-committed kill gates, and a 90-day discovery plan. When the evidence kills the pitch, it tries the standard reframes (bill a different payer, sell through the channel that owns the trigger, go agentic, go narrow) before calling it dead.
- **`discovery-pass-designer`** — the authoring layer. Breaks any research objective into sections with separate retrieve → synthesize → judge legs, puts the cheapest capable model on each leg, and picks a runtime: one conversation, parallel subagents, or a handoff to another provider (e.g. OpenAI/Codex does the legwork, Claude makes the call).

Two rules run through both: keep the evidence attached to every judgment so it can be audited, and have the legwork model stop before the verdict so the final call is a genuine second opinion.
